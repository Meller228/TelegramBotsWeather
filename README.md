# 🌤 Telegram Weather Bot

Бот для получения текущей погоды в любом городе.

## 🛠 Технологии
* Python 3
* pyTelegramBotAPI
* Requests (для работы с API погоды wttr.in)

## ⚙️ Как пользоваться
* `/start` — запуск бота
* Напишите название города, и бот пришлет погоду.

## 🚀 Как запустить локально
1. Установите зависимости: `pip install pyTelegramBotAPI requests`
2. Вставьте свой токен в переменную `TOKEN` в файле `weather.py`
3. Запустите: `python weather.py`
